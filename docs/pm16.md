# PM16 small-model programs

PM16 version 1 places code in one segment and shares a second segment between
data and the stack. Rivet starts the program with `CS=0038h` and
`DS=ES=SS=0040h`. It copies the initialized data, clears the BSS, and pushes
a four-byte far return address. Put a DOS exit code from 0 through 255 in `AX`
and return with `RETF`. [Demo source](../examples/demo.asm)

## Image layout

Write the 32-byte header first, then the code bytes and initialized data
bytes. The header fields are little endian. BSS and stack space take up no
bytes in the file.

| Offset | Bytes | Meaning |
| --- | --- | --- |
| 0 | 4 | ASCII `PM16` |
| 4 | 2 | Version `0100h` |
| 6 | 2 | Header size in bytes, 32 |
| 8 | 2 | Small memory model, 1 |
| 10 | 2 | Code size, 1 through `FF00h` bytes |
| 12 | 2 | Entry offset from the start of code, smaller than the code size |
| 14 | 2 | Offset where Rivet places the initialized data, at least `0100h` |
| 16 | 2 | Initialized data size in bytes |
| 18 | 2 | Number of bytes Rivet clears after the initialized data (BSS) |
| 20 | 2 | Stack reservation in bytes, even and at least 512 |
| 22 | 2 | Stack top before Rivet pushes the return address, even and at most `FFFEh` |
| 24 | 4 | Exact file size in bytes |
| 28 | 4 | Reserved, zero |

The data offset plus the initialized data and BSS sizes must be at most the
stack top minus the stack reservation.

## DOS file requests

The demo uses version 1 of the file request record below. Before each call,
fill in the fields for the operation and set unused and output fields to zero.
Set `AX=0100h` and `CX=32`, point `ES:BX` at the writable record in the
program's data segment, and call `INT 60h`.

| Offset | Bytes | Meaning |
| --- | --- | --- |
| 0 | 2 | Request version, 1 |
| 2 | 2 | Operation |
| 4 | 2 | Access mode for open |
| 6 | 2 | Rivet file handle for read, write, seek, or close |
| 8 | 2 | Buffer kind, 1 for a selector and offset |
| 10 | 2 | Seek origin |
| 12 | 4 | Buffer offset then selector, two bytes each |
| 16 | 4 | Buffer length |
| 20 | 4 | Signed seek displacement |
| 24 | 4 | Result, written by Rivet |
| 28 | 2 | Original DOS error, written by Rivet |
| 30 | 2 | Reserved, zero |

Create (3) takes a path with a terminating NUL. Include that byte in the
buffer length. Read the returned handle at offset 24 and put it at offset 6 in
the write (5) and close (7) requests. Write reports the number of bytes written
at offset 24.

Carry clear means success. Carry set means `AX` holds a Rivet error code.
After a write, check both carry and the byte count, since a successful call
can write fewer bytes than requested.
