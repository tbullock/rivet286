# PM16 small-model programs

Rivet loads a PM16 version 1 image into separate code and data segments.
The entry selectors are CS=0038h and DS=ES=SS=0040h. The loader copies the
initialized data, zeroes BSS, and puts a far return address on the client stack.
Return with `RETF` and a DOS exit code of 0 through 255 in AX.

## Image layout

The file contains a 32-byte header, then code and initialized data, in that
order. All header fields are little endian.

| Offset | Bytes | Meaning |
| --- | --- | --- |
| 0 | 4 | ASCII `PM16` |
| 4 | 2 | Version 0100h |
| 6 | 2 | Header size, 32 |
| 8 | 2 | Small-model profile, 1 |
| 10 | 2 | Code size |
| 12 | 2 | Entry offset in code |
| 14 | 2 | Initialized data offset in the data segment, at least 0100h |
| 16 | 2 | Initialized data size |
| 18 | 2 | BSS size immediately after initialized data |
| 20 | 2 | Even stack reservation of at least 512 bytes |
| 22 | 2 | Even initial stack pointer, at most FFFEh |
| 24 | 4 | Exact file size |
| 28 | 4 | Reserved, zero |

## DOS file requests

Call `INT 60h` with AX=0100h, CX=32, and ES:BX pointing to a writable
request record in the client data segment. Unused fields start at zero.

| Offset | Bytes | Meaning |
| --- | --- | --- |
| 0 | 2 | Request version, 1 |
| 2 | 2 | Operation |
| 4 | 2 | Access mode for open |
| 6 | 2 | Rivet file handle for read, write, seek, or close |
| 8 | 2 | Buffer kind, 1 for a selector and offset |
| 10 | 2 | Seek origin |
| 12 | 4 | Buffer offset then selector, two bytes each |
| 16 | 4 | Buffer length |
| 20 | 4 | Signed seek displacement |
| 24 | 4 | Result, written by Rivet |
| 28 | 2 | Original DOS error, written by Rivet |
| 30 | 2 | Reserved, zero |

The demo uses create (3), write (5), and close (7). Create takes the path
including its terminating NUL and returns the handle. Write returns the byte
count. Carry clear indicates success. Carry set indicates failure, with the
Rivet status in AX. Check both the status and result when writing data.
